# Bug Trace — Exam Arena Frontend

> One entry per bug. Readable without prior context. Copy the template for a new bug.

## Template

```markdown
## Bug: <short title>     ·  opened <date> · status: <open|fixed|wontfix>

### Found
- Where: <page/component/service + file:line>
- Symptom: <what the user saw / wrong behavior>

### Tried / not tried
- <attempt + result>

### Root cause
- <what actually caused it>

### Fix
- <what changed, which files>

### Verified
- <command run / manual check + result>
- [ ] typecheck · [ ] build · [ ] APK (if affected) · [ ] manual test

### Rollback
- <commit to revert if the fix misbehaves>
```
